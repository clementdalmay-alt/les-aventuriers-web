# Les Aventuriers — appli web

Version installable du jeu **Les Aventuriers**, servie par GitHub Pages : https://clementdalmay-alt.github.io/les-aventuriers-web/

Ce dépôt ne contient que l'appli assemblée. Le code source est ailleurs (dépôt privé) : ne pas modifier ces fichiers à la main, ils sont remplacés à chaque version.

## Installer

- **Android (Chrome)** : ouvrir le lien, puis « Installer l'appli » (bouton sur l'accueil du jeu, ou menu ⋮ → Installer l'application).
- **iPhone (Safari)** : ouvrir le lien dans Safari, toucher le bouton Partager, puis « Sur l'écran d'accueil ».

Le jeu marche ensuite hors connexion. Quand une nouvelle version sort, un bandeau « Recharger » apparaît sur l'accueil.

Sur iPhone, Safari peut effacer les données d'un site après quelques semaines sans visite : pensez à sauvegarder votre code de partie (Réglages → Sauvegarder mon code de partie).

## Check-list sur téléphone (à chaque nouvelle version importante)

1. Ouvrir le lien : l'accueil s'affiche avec les bonnes polices (titre « Les Aventuriers » en lettres grattées).
2. Installer l'appli (Android : bouton Installer ; iPhone : Partager → Sur l'écran d'accueil). L'icône du totem apparaît.
3. Lancer l'appli depuis l'icône : plein écran, sans barre d'adresse.
4. Commencer une partie, jouer deux jours, fermer l'appli, la rouvrir : « Reprendre » est proposé.
5. Mode avion : rouvrir l'appli, reprendre la partie, lancer le Défi du jour et un code de défi.
6. Réglages → Sauvegarder mon code de partie : copier le code, puis l'importer (Transfert → Sur cet appareil).
7. Sur iPhone : l'aide « Sur l'écran d'accueil » se ferme et ne revient pas ; pas de réglage Vibrations.

Polices : Rubik Dirt, Karla, Caveat (SIL Open Font License, voir `fonts/LICENCE-*.txt`).
